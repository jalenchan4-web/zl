# 八字命盘工作台

一个静态网页原型，支持单人八字命盘与双人八字合盘分析。

## 功能

- 单人命盘：四柱、十神、藏干、职业方向、近年节奏、人生发展曲线
- 双人合盘：缘分结构、事业生活匹配、星座辅助、双人发展曲线
- 掌纹式曲线：生命/生活线、事业线、感情线

## 本地预览

```bash
python3 -m http.server 4173
```

然后打开：

```text
http://127.0.0.1:4173/index.html
```

## GitHub Pages

这是纯静态站点，推送到 GitHub 后可直接用 GitHub Pages 从 `main` 分支根目录发布。
